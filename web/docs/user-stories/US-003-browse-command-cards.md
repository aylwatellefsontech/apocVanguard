# US-003 Look up command cards

**As a** player  
**I want to** browse command / strategic asset cards by faction or all at once  
**So that** I can see card text before I add cards to a list

## Acceptance criteria

- Browse has a Cards section with All plus each card faction and its count.
- Selecting All or a faction shows matching cards in a readable stack.
- I can search cards by name or text.
- The cards view is reflected in the URL (`?cards=`).
