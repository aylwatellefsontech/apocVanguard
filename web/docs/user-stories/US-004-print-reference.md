# US-004 Print a faction list or card set

**As a** player  
**I want to** print a faction army list or the command cards I am looking at  
**So that** I can take a paper reference to the table

## Acceptance criteria

- In army-list mode, Print opens a printable HTML view of the selected faction’s units.
- In cards mode, Print Cards opens a printable sheet of the currently filtered cards.
- Printing does not change any saved army or draft.
