# US-013 Print a saved roster or its cards

**As a** player  
**I want to** print the army I actually saved, not just a generic faction list  
**So that** my paper copy matches options, points, and cards

## Acceptance criteria

- Print Army opens a printable view of the selected saved roster (disabled when there are no units).
- Print Cards opens a printable sheet of that army’s command cards (disabled when there are no cards).
- Export remains available from My Armies as well as from the builder.
