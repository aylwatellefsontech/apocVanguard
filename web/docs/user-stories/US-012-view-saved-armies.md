# US-012 Review a saved list at the table

**As a** player with saved armies  
**I want to** open a list and flip between units, cards, or both  
**So that** I can reference the army during a game

## Acceptance criteria

- My Armies lists saved armies with name, faction(s), points, and last updated date.
- Selecting an army shows its roster and cards.
- I can cycle the view between Army, Cards, and Show All.
- I can expand or collapse individual entries or all entries / cards.
- Organized lists appear grouped by detachment; multi-faction lists show faction names.
- I can jump to Build Army to edit the selected list.
