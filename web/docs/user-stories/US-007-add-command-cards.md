# US-007 Add command cards to a list

**As a** player building a list  
**I want to** add command cards to the same army as my units  
**So that** I have a deck ready for the game

## Acceptance criteria

- Build Army can switch from units to cards.
- I can browse All cards, base Apocalypse cards, or a faction’s cards, and search them.
- Adding a card appends it to the army’s card list.
- I can remove cards from the list.
- Saved armies store cards with the roster.
