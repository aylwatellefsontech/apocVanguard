# US-016 Install the app on a device

**As a** player  
**I want to** install the companion app on my phone or computer  
**So that** I can open it like a native app at the table

## Acceptance criteria

- When the browser can install the app and it is not already installed, Home shows an install action.
- Using install triggers the browser install prompt when one is available.
- If a prompt is not available, Home shows a short hint for how to install from the browser UI.
- The install section is hidden once the app is running as an installed PWA.
