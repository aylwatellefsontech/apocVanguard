# US-002 Look up faction datasheets

**As a** player preparing a game  
**I want to** browse a faction’s units and open a full datasheet  
**So that** I can check stats, weapons, abilities, and points without opening the source markdown

## Acceptance criteria

- Browse lists every bundled faction with a unit count.
- Selecting a faction shows its units grouped by type (HQ, Troops, Elites, Fast, Heavy, Transport, Air, Lord).
- I can search units by name.
- Selecting a unit shows its datasheet (stats, profiles, weapons, abilities, keywords, options).
- The selected faction is reflected in the URL so I can share or bookmark it.
- I can start a new list from Browse via Create Army.
