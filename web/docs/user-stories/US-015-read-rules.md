# US-015 Read the Vanguard rules

**As a** player  
**I want to** read the Apocalypse Vanguard rules in the app with a table of contents  
**So that** I do not need a separate rules file at the table

## Acceptance criteria

- Rules renders the bundled rules markdown.
- A contents list of headings lets me jump to a section.
- Jumping to a section updates the URL hash and scrolls that heading into view.
- On a phone, contents and the rules body are separate panels with a back control.
