# US-006 Configure unit profiles and options

**As a** player building a list  
**I want to** pick a unit’s profile and toggle wargear or other options  
**So that** the roster points match the models I will put on the table

## Acceptance criteria

- If a unit has alternate profiles, I can choose which profile the roster entry uses.
- Options can be toggled on or off; exclusive groups, choose-one, per-model, and limited options follow those constraints.
- Changing options updates that entry’s points and the army total.
- I can reopen a roster entry to change its options after it was added.
