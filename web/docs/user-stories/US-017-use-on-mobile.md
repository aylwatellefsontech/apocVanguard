# US-017 Use the app on a phone

**As a** player using a phone  
**I want to** move through one panel at a time and use the back control to return  
**So that** the three-column desktop layout is still usable on a small screen

## Acceptance criteria

- Browse, Build Army, My Armies, and Rules switch to a stacked mobile layout at the mobile breakpoint.
- I see one panel at a time (for example factions → list → datasheet, or list → army detail).
- A back bar and the browser back button step to the previous panel instead of immediately leaving the page.
- Build Army has a mobile bar for switching among factions, the unit/card list, the datasheet, and the roster.
