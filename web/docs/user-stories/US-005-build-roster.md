# US-005 Build an army roster

**As a** player  
**I want to** add units from one or more factions to a named roster and see the points total  
**So that** I can assemble a Vanguard list for a game

## Acceptance criteria

- Build Army lets me pick a faction, search its units, open a datasheet, and add a unit to the roster.
- Each roster entry records the unit, chosen profile, options, and points.
- The roster shows a running points total.
- I can name the army.
- I can add units from more than one faction; the list then shows faction names on entries.
- I can remove entries and start a new army (with a confirm if I already have work).
- I can switch into building from an existing saved army via `?armyId=`.
