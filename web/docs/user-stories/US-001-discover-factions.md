# US-001 Discover factions and jump into the game

**As a** player new to Apocalypse Vanguard  
**I want to** land on a home page that explains the game and shows the factions  
**So that** I can start reading rules or browsing a list without hunting through files

## Acceptance criteria

- Home explains that Vanguard is a smaller-footprint fan version of 40k Apocalypse (2019).
- Home links to the rules.
- Home shows a grid of factions that have icons; tapping a faction opens Browse for that faction.
- Home offers a Progressive Web App install action when the app is not already installed.
- The main nav is available from Home (Browse, My Armies, Build Army, Rules).
